# ADR-0005：独立组件仓库与索引仓库

状态：已接受（用户要求将现有 monorepo 改为 multi-repo 并保留索引仓库）。

## 决定

提取 107-backend 和 107-frontend，保留各自目录的 Git 历史。
原 107-workspace 维护全局文档、部署、认证适配、集成工具与测试；
通过 Git 子模块固定组件提交。单仓检查和构建不依赖相邻源码目录。

API 定义仍由后端路由导出，前端提交固定版本快照与来源，不新增契约仓库。
文档按职责随仓库维护，不建立独立 docs 仓库。后端维持模块化单体。

## 影响

跨组件改动需要先提交和推送组件，再更新索引指针并验收。
组件镜像独立发布；索引提交负责组合版本。GitHub 原有 Issue/PR 留在原仓库。
产品规则和 GR/ADR 文档引用由索引仓库的集成检查保护。
详情见 [多仓库协作](../contributing/multi-repo.md)。
