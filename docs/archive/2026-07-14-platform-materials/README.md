# Platform Source Materials Archive

This directory preserves three source materials collected during the backend
reinitialization review. They provide product, training, and runtime context;
they are not normative backend specifications.

- [training-107-competition.pdf](training-107-competition.pdf): 107 cluster and
  competition training material.
- [算力平台及算力平台赛道介绍.pdf](算力平台及算力平台赛道介绍.pdf): computing platform
  and competition-track introduction.
- [流程参考.md](流程参考.md): explanatory notes about the relationship between
  107 Workspace, Slurm, and Apptainer.

For normative architecture and accepted backend scope, use the
[backend design](../../superpowers/specs/2026-07-13-workspace107-backend-design.md)
and the
[backend reinitialization review](../../reviews/2026-07-14-backend-reinitialization/README.md).
