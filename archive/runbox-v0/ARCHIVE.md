# RunBox v0 Archive

This directory preserves the original single-user RunBox implementation from
commit `72d975c`. It is not imported by the active backend.

Reusable behavior is reimplemented behind backend ports: non-blocking cluster
calls, structured errors, reconnectable SSE logs, and explicit cancellation.
Generated bytecode and package metadata are intentionally excluded from the
finished archive.

The archived README refers to a sibling `hpc-helper` checkout that was never
tracked by this repository. Its upstream provenance and the reasons it is not
vendored are recorded in
[`docs/references/engineering/hpc-helper.md`](../../docs/references/engineering/hpc-helper.md).
The historical README is otherwise left unchanged.
